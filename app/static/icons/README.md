# PWA Icons

Diese Icons werden für die Progressive Web App (PWA) Installation benötigt.

## Icons generieren

Führe das Script aus (benötigt ImageMagick):

```bash
cd app/static/icons
./generate-icons.sh
```

## Eigene Icons verwenden

Ersetze die generierten PNG-Dateien mit deinen eigenen Icons in folgenden Größen:
- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192 (wichtig für Android)
- 384x384
- 512x512 (wichtig für Android)

## Temporäre Platzhalter

Bis eigene Icons erstellt werden, verwendet die App einfache Diamant-Icons in Lila (#8B5CF6).
